Database

Getting VDJdb in plain text format

The latest version of the VDJdb database in tab-delimited format is available as a single archive in GitHub release section. AI-predicted TCR:pMHC structures can be found at our HuggingFace repository. Inferred paratope (V+CDR3) motifs can be found in the corresponding GitHub repository.

Contributing

Users interested in contributing TCR sequences of known antigen specificity to the database should read the instruction at the following link. To submit the contribution use the issue system of the VDJdb repository. If you are not familiar with GitHub you can file your submission by creating a new issue and attaching your files. Advanced users can use the pull-request system.

TCR structure modeling

TCRmodel2 (accessed 5 August 2025) software was selected because of its high performance in TCR structure modeling, straightforward installation and usage, and free distribution. The tool was run with default parameters and the AlphaFold database provided by the authors. Only VDJdb records containing both TCR α and β chains were selected for modeling and subsequent processing. To prepare each VDJdb record for modeling, we used the stitchr Python library (v. 1.3.1) to generate complete TCR sequences and retrieved MHC sequences from the IMGT database (accessed 12 August 2025). Modeling was performed on the Aldan3 computing cluster and orchestrated via the SLURM Workload Manager. Of the five structures generated for each record, only the best-ranked structure was retained. Generation of one VDJdb record took approximately 10 minutes of wall-clock time.

To ensure better comparability among the models, we subsequently aligned them twice using the PyMOL Python API. The first alignment was performed across all structures of the same MHC class, and the second alignment was performed among structures recognizing the same epitope. Following alignment, the 3D Cα coordinates of the CDR3 loops and the peptide from each structure were projected onto a single 2D plane that was uniform for all structures. Inter-chain amino acid contacts were annotated when the distance between any atoms of two residues was less than 5 Å. The resulting 2D projections with marked contacts (Skeleton plot) for the VDJdb records are now displayed in the VDJdb structure browser. Each VDJdb record for which a structure was generated was annotated with the AlphaFold2 ranking confidence, the number of TCR–peptide contacts, and the scanning and pitch angles calculated using the stcrpy library (v. 1.0.6). PDB files of the generated structures, tables of contacts, and Cα coordinates are freely available via the structure browser interface and on Hugging Face.

Software

Standalone application

A command line interface software (VDJmatch) should be preferred in cases when huge amounts of immune repertoire sequencing data are being analyzed or when users are interested in obtaining unprocessed output for carrying out statistical analysis of the results on their own. VDJmatch is a command line tools written in C++17 that comes together with example usage scripts and notebooks in Python, for additional details see the README file in the repository linked above. You can find the latest version of the software here.

Web server (Advanced)

VDJdb web browser application is an open-source software implemented using Play Framework, Angular and Semantic UI. A standalone browser version of the software can be installed locally, the following link contains the software package and installation instructions.

Public API and documentation

VDJdb web browser application uses public and fully documented API to query the database. The documentation, API description and usage examples can be found at ReadTheDocs website.
