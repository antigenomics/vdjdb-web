Multisample analysis

Multisample analysis annotates several of your samples against VDJdb in a single run, using one set of search parameters, so the results can be compared directly.

Select the samples you want to include (individually, or by tag), set the annotation parameters, and click Annotate. Every selected sample is queried with exactly the same settings.

The summary counts the matches of each sample grouped by epitope, epitope species, epitope gene or HLA allele, and plots the samples side by side within each group, so specificities shared between samples or restricted to one of them can be read off the chart.
