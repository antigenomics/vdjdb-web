Batch annotation of TCR sequences

Connecting

Here you can upload your T-cell receptor repertoire sequencing data and annotate it by performing batch queries of the VDJdb database.

To proceed with the analysis, go to the upload section, add your samples, and click on the sample name in the panel on the left. After running the annotation, you can view the table of VDJdb matches (click Table below the sample name) and annotation summary charts (click Charts below the sample name).

If you want to annotate all your samples together and get a summary statistics report for your dataset, click All samples in the panel on the left.

Input formats. VDJtools, AIRR and MiXCR tables are accepted, plain or gzipped. There is nothing to select: the format is read from the column header of the file you upload, and a header that cannot be placed as one of the three is rejected rather than guessed at. Every accepted file is converted to a VDJtools table on upload, so the format shown against a stored sample is the one it arrived in.

The chain is derived the same way, from the J segment call or an explicit locus column. Leave it on Guess and a file holding both chains is split into two samples, name_TRA and name_TRB; name a chain instead and that is treated as an assertion about the file, keeping only those records.

Note that limits on the number of samples, sample file size and number of clonotypes (unique TCR sequences) apply.
