P-value is a Beta-Binomial upper tail: of the clonotypes in this sample, how many matched this epitope, against how often a healthy control repertoire of 100 000 clonotypes of the same species and chain matches it by chance. The control rate carries a ½-count prior, so an epitope the control never reached is treated as rare rather than impossible. It counts clonotypes only, so neither the read-count weighting nor the axis scaling changes it. P-adj is Benjamini-Hochberg across every epitope tested in the sample. No p-value is shown when the search filters differ from those the control was measured under.
